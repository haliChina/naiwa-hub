## 本地预览 / 部署

纯静态单文件，无构建步骤：

```bash
# 本地预览
npx serve .
# 或直接用浏览器打开 index.html
```

Vercel 部署：导入本仓库即可，构建命令留空，输出目录为项目根目录。
